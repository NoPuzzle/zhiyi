# 知易 / Zhiyi Product Brief

## Product Identity

**Chinese name:** 知易  
**English name:** Zhiyi  
**Optional full expression:** 知易 · 观象  
**Tagline:** 以象入易，以问观心  
**Secondary tagline:** 看见变化，理解自己

Zhiyi is a mobile-first visual Yi Jing / Zhouyi learning and reflection tool. It helps users learn through images, trigrams, hexagrams, line positions, changing lines, transformed hexagrams, and calm ink-style motion. It also gives users a structured way to reflect on situations, emotions, decisions, and recurring patterns.

Zhiyi is not a deterministic fortune-telling product. It should not claim to predict fate, change destiny, or guarantee outcomes.

## Meaning Of The Name

1. **知《易》**  
   Learn and understand the Yi Jing / Zhouyi, including Yin/Yang, Eight Trigrams, Sixty-Four Hexagrams, changing lines, and classical text.

2. **知变化**  
   Understand change, transformation, timing, position, relationship, and recurring patterns.

3. **知易行难**  
   Understanding can be easier than action. Each interpretation should eventually guide the user back to reflection and one small practical action.

## Product Vision

Zhiyi should feel like a quiet study room for observing change. The product uses hexagram images as the visual center, then supports learning and reflection through careful language, plain explanations, and practical prompts.

The app should help users:

- Learn Yi Jing concepts progressively.
- See hexagrams as visual structures, not only as text.
- Ask reflective questions without treating the answer as fate.
- Understand tension, timing, position, and transformation.
- End each reading with one small action.

## Product Principles

- Learning and reflection come before interpretation.
- Hexagram imagery should be central.
- Explanations should be structured, calm, and non-absolute.
- The user should feel invited to observe, not pressured to believe.
- Classical text should be handled with respect and clear sourcing.
- Original plain-language explanations should be written for this product, not copied from competitors or modern copyrighted translations.
- Interpretation should support emotional clarity, not dependency.

## Safety And Content Boundaries

Zhiyi must avoid deterministic claims.

Do not use wording such as:

- "predict your fate"
- "change your destiny"
- "guaranteed result"
- "this will definitely happen"
- "magic"

Preferred wording:

- "this suggests"
- "one possible reading is"
- "this invites reflection"
- "from the image of the hexagram, we can observe..."
- "this may point to..."
- "a useful question here is..."

Interpretations should not replace professional advice in medical, legal, financial, or mental health contexts. In high-stakes contexts, the app should encourage users to seek qualified help and treat the reading as reflection only.

## Core Interpretation Framework

Every reflective reading should follow this structure:

1. **象 / Image**  
   What the hexagram image shows.

2. **辞 / Text**  
   Relevant original text, judgment, image text, or line text.

3. **理 / Principle**  
   The underlying principle of change, timing, position, or relationship.

4. **用 / Application**  
   How this may apply to the user's question or context.

5. **问 / Reflection**  
   A question that helps the user reflect.

6. **行 / Small Action**  
   One small practical action, connecting to 知易行难.

## Main User Goals

### 学易

Users should be able to learn:

- Yin and Yang.
- The Eight Trigrams.
- The Sixty-Four Hexagrams.
- Line positions.
- Changing lines.
- Transformed hexagrams.
- Opposite hexagrams.
- Reversed hexagrams.
- Mutual hexagrams.
- Original classical text.
- Plain-language explanations.

### 问卦

Users should be able to:

- Ask a reflective question.
- Build or cast a hexagram.
- See the hexagram generated line by line.
- Identify changing lines.
- See the transformed hexagram.
- Receive a structured reflective interpretation.
- Choose one small practical action.

## MVP Scope

V0.1 should include:

- Next.js App Router project foundation.
- TypeScript.
- Tailwind CSS.
- Mobile-first responsive layout.
- Static local data for trigrams and selected hexagrams.
- SVG-based hexagram rendering.
- Calm line-generation animation.
- Basic learning pages for Yin/Yang, trigrams, and hexagrams.
- A question input flow.
- A local hexagram generation or manual build flow.
- Changing line display.
- Transformed hexagram calculation.
- Interpretation template using 象 / 辞 / 理 / 用 / 问 / 行.

V0.1 should not include:

- Database.
- Login.
- Payment.
- External AI API.
- Real API keys.
- User account history.
- Social sharing.
- Deterministic fortune-telling copy.

## Content Model

Content should be local static data first. The app should separate:

- Canonical identifiers and structural data.
- Classical source text.
- Product-authored plain-language explanations.
- Interpretation templates.
- UI copy.

This keeps future content review, localization, and data expansion manageable.

## Initial Success Criteria

V0.1 is successful when a user can:

- Open the app on mobile.
- Learn the difference between Yin/Yang and basic line types.
- Browse trigrams and hexagrams visually.
- Ask a question.
- Generate or build a hexagram.
- See changing lines and transformed hexagram.
- Read a non-deterministic structured interpretation.
- Leave with one small action.
